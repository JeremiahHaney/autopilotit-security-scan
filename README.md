# AutoPilot IT – Free Windows Security Scan

This tool runs locally on Windows to check basic security and protection status, including updates, Defender health, encryption, and common risk gaps.

It generates a clear PDF report you can review or share.

- Runs locally
- No agent install
- No data uploads
